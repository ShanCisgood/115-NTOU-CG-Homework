本儲存庫主要包含五個作業的資料夾，每個資料夾內皆有對應的程式碼與專案設定檔：

- `01257121_HW1/`：第一次作業專案檔案與報告
- `01257121_HW2/`：第二次作業專案檔案與報告
- `01257121_HW3/`：第三次作業專案檔案與報告
- `01257121_HW4/`：第四次作業專案檔案與報告
- `01257121_HW5/`：第五次作業專案檔案與報告
- `hw1(5).pdf`：作業一的題目
- `hw2_car.pdf`：作業二的題目
- `hw3(6).pdf`：作業三的題目

> **註記**：各作業資料夾內包含了 C++ 原始碼（如 `main.cpp`）及 Visual Studio 專案相關設定檔。根目錄則包含部分作業的說明文件與使用的圖片資源。

## 如何開啟與執行專案

本課程作業使用 **C++** 撰寫，並透過 **Visual Studio** 進行開發與編譯。請依照以下步驟開啟與測試作業：

1. **取得專案**：
   將此儲存庫 clone 到您的電腦上：
   ```bash
   git clone https://github.com/ShanCisgood/115-NTOU-CG-Homework.git
   ```
2. **開啟解決方案**：
   - 進入想要查看的作業資料夾（例如 `01257121_HW1/`，接著進入內部的專案目錄）。
   - 找到副檔名為 `.sln` 的檔案 (例如 `CG_hw1.sln`)。
   - 點擊兩下以 **Visual Studio** 開啟。
3. **編譯與執行**：
   - 在 Visual Studio 載入專案後，請在上方工具列選擇對應的架構（例如 `x64`）。
   - 按下 `F5`（開始偵錯）或 `Ctrl + F5`（啟動但不偵錯）即可自動編譯並開啟圖學視窗。
4. **程式操作**：
    - 應該可以找到一個 .pdf 檔，裡面有說明。
